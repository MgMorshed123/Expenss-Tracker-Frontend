# 🎯 ExpenseTracker Frontend

A modern, responsive **expense tracking web app** built with **React**, **Tailwind CSS**, **Recharts**, and **Lucide icons**. Track your expenses effortlessly and visualize your spending with interactive charts.

## 🛠 Prerequisites
- Node.js ≥ 14.x  
- Browser with JavaScript enabled  
- SMTP server configured in backend for sending OTP emails (currently using Gmail SMTP)  

> ⚠️ Note: OTP is sent via email after registration. For testing, check your Gmail inbox.
